# Invitro notification bot

The goal of this project is development of a notification bot for Invitro.ru doctor appointment system.
For now the target is one concrete doctor: https://www.invitro.ru/kurgan/vrachi/ginekolog/19143/
Notifications should be sent using Telegram bot, ask me for credentials when it is needed.
Implementation should be easily deployable on a Linux VPS with limited resources running NixOS.
It is preferrable to implement it in compilable language like Rust but that needs deeper investigation.
